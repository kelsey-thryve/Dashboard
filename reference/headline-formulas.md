# 200+ Headline Formulas

Shared reference for all Thryve agents — ad headlines, email subject lines, landing page
headlines, social hooks, any copy where the opening line matters. Source: "200+ Headline
Formulas Used by Digital Marketing Experts."

Fill in the bracketed variable, keep tone matched to the brand/client, and generate several
variations across categories before picking a direction.

## Variable glossary

| Variable | Meaning | Example |
|---|---|---|
| desirable skill | Something the audience wants to learn | "build a 6-week program" |
| desirable status | Who they want to become | "a full-time fitness creator" |
| specific metric | Measurable result | "500 new subscribers" |
| specific ROI | Revenue/financial result | "$5K/month from memberships" |
| social proof result | Credibility signal | "100 5-star reviews" |
| authority indicator | Recognition/credential | "featured in Men's Health" |
| tactic | A method or strategy | "email marketing" |
| challenge/pain point | What they're struggling with | "client retention" |
| offer | The specific promotion | "50% off first month" |
| resource | Guide, ebook, video, etc. | "free training" |
| title | Job/identity label | "personal trainers" |
